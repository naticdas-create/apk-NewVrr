# Gerar o APK sem Android Studio
1. Crie uma conta em github.com e um repositório novo (privado serve), chamado NovaVR.
2. Envie TODO o conteúdo desta pasta para o repositório (botão "Add file > Upload files"; arraste os arquivos e pastas, inclusive a pasta oculta .github).
3. Vá na aba **Actions**, abra "Build APK" e aguarde uns 5 a 8 minutos (ou clique em "Run workflow").
4. Quando ficar verde, clique na execução e baixe **NovaVR-apk** em "Artifacts". Descompacte e instale o app-debug.apk no celular
   (permita "instalar apps de fontes desconhecidas").
Se a execução ficar vermelha, copie o final do log e me envie.
